# Artemis Financial project files

- `Original_ArtemisFinancial`: original CS 305 source, with private keystores and generated build files omitted and the old password removed.
- `Enhanced_ArtemisFinancial`: Merkle tree enhancement, tests, demo, and setup instructions.

The narrative is on the portfolio's Artemis page. To run the project, open Enhanced_ArtemisFinancial in IntelliJ IDEA or VS Code and follow README.md. The PowerShell core-check script runs without Maven dependencies. TEST_RESULTS.txt records the completed checks and the application tests that still need to run.
